abstract = "Cloud based video delivery platforms serve a significant fraction of the entire Internet traffic and are continuously expanding with the growing demand. We study the provisioning of the server cluster to deploy at each location in such systems. We optimize the right server count, peering bandwidth, and server configuration as the disk size and the necessary SSD and/or RAM caches to sustain the intensive I/O load. Our analyses are based on actual server traces from a global content delivery platform. Our optimization captures the interaction of cache layers in each server, the interplay between egress/disk capacity and network bandwidth, storage read/write constraints and storage prices."
