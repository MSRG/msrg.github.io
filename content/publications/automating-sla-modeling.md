abstract = "Service Level Agreements (SLAs) define the level of service that a service provider must deliver. An SLA is a contract between service provider and consumer, and includes appropriate actions to be taken upon violation of the contractual obligations. However, implementing an SLA using existing IT infrastructure is difficult, requiring a lot of manual effort to translate an SLA into code, model it with the given programming language, and ensure the required monitoring support is available for efficient monitoring and tracking of the SLAs."
